# 板块核心个股主力排行扩充至 Top 50 设计规范

## 1. 需求与背景
用户在点击板块时，当前界面右下方“核心个股主力排行”仅显示 10 只个股，对于大板块（如半导体、新能源、白酒等成分股众多的板块），无法全面观察二线龙头与成分股的资金梯队分布。
为了给投资者提供更深度的成分股资金分布视野，需将该接口与前端展示扩充至 Top 50。

## 2. 系统设计

### 2.1 后端 API 扩展
- **文件**：`backend/app/main.py`
- **端点**：`GET /api/sectors/{code}/stocks?limit=50`
- **实现细节**：
  - 增加可选查询参数 `limit: int = 50`。
  - 上游东财 API 参数中 `pz` 设为 `str(min(max(limit, 1), 100))`。
  - 缓存保持基于 `code` 的 30 秒内存 TTL 缓存；因单条个股记录极小（约 100 bytes），50条数据仅占约 5KB，内存开销可忽略不计。

### 2.2 测试用例更新与扩展
- **文件**：`backend/tests/test_main.py`
- **更新**：
  - 更新 `test_get_sector_stocks_endpoint`，断言传给东财的 `pz` 参数为 `"50"`。
  - 新增测试支持自定义 `limit` 参数校验。

### 2.3 前端展示优化
- **文件**：`frontend/src/App.vue`
- **优化点**：
  - 核心个股列表标题优化为：`{{ selectedSectorName }} 核心个股主力排行 (Top {{ coreStocks.length }})`。
  - 序号与行排版优化：确保 1-50 序号显示整齐，保留 `cursor-pointer` 点击弹窗能力。
  - 重新构建前端静态产物 (`npm run build`)。

## 3. 验收标准
- 后端所有测试 (25+ tests) 通过。
- 启动服务后调用 `/api/sectors/BK0437/stocks`，默认请求 `pz=50`。
- 前端页面正常显示多于 10 只个股并可平滑向下滚动，且点击任意第 1~50 只个股均可唤起个股分时/日K深度弹窗。
